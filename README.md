# Order Management System (Tkinter + SQLite)

This is a simple Python application created for the **Data Handling** subject.

## Features
- Manage Customers, Products, and Orders
- Add / Edit / Delete rows
- Import and Export CSV/Excel files
- Data validation (email format, numeric fields)
- Linked foreign keys between tables
- Generate Reports using Pandas + Matplotlib

## Tools Used
- Python 3.12
- Tkinter (GUI)
- SQLite (Database)
- Pandas (Data handling)
- Matplotlib (Visualization)
